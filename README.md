# Compass Linux

Compass Linux is a source-based Linux distribution focused on **coherence and purity**.

It draws inspiration from the primitives and ideas of **Gentoo**, **Funtoo**, **Source Mage**, and many others, while aiming to make them **elegant, lightweight, and fast**.

It uses the **Blueprint** package manager, which, i guess, is ***NICER***.

## Development & Community

Development, discussion, and project coordination happen over IRC.

Come join us in **`#compass`** on **`irc.libera.chat`**.

## Status

**Very early stage.**

Things are likely to be incomplete, broken, or changing rapidly. Don't expect everything to work yet.
